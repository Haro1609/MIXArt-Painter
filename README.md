# MIXArt-Painter
MIXArt Painter là ứng dụng vẽ kỹ thuật số với giao diện tối giản, canvas rộng và bộ công cụ dễ dùng. Chọn cọ, chỉnh kích thước và độ đậm, phối màu theo ý thích, vẽ trên nhiều lớp và hoàn tác khi cần. Khi hoàn thành, bạn có thể xuất tác phẩm thành ảnh PNG. Dù chỉ phác thảo nhanh hay thử nghiệm ý tưởng mới.
